01 / WEB APP

Lettuce

Investment research tool

I made an investment tool focused on providing information to be used for choosing stable long term investments. It uses the SEC EDGAR free API to retrieve EPS, dividends, financial statements and company names. Cboe supplies prices and a delayed quote. FRED supplies the Treasury yield and S&P 500 history used for cost of capital.

Node.js · Vanilla JavaScript · SVG

02 / WEB GAME

Square Game

A little card game I made

This summer, I really enjoyed playing a board game called Iota with my family. When I left for school, I wanted to keep playing and made a solution. I named it Square game. It's an online version of the board game with some features inspired by chess.com, like multi day turns and post game stats. It uses Supabase to host a Postgres database storing each game, hashed login codes and account profiles. No passwords are saved. It uses Resend to send turn and code emails.

03 / RESTORATION

Bluey

1995 Toyota 4Runner

This car is so fun to drive. It's very rewarding to spend hours fixing something and then be able to enjoy it every time you drive the car. So far I've done all the work myself (with some help from family) and don't plan on taking Bluey to an autoshop anytime soon.

The first fix was the rear brake lines, which had rusted and cracked while the car was sitting for 7 years. One of the bolts which hold up the brake lines snapped so there's a welded piece in the back connecting the brake line to the chassis.

Next was a full interior refurbishment to remove the urine odor. This involved removing all the seats, carpet, trim and door panels. Everything was steam cleaned and the car now smells normal.

After that, I diagnosed and fixed the tailgate window assembly. It turned out to be rusted window supports which caused the window to not roll up or down sometimes. The whole assembly had to be disassembled to replace the parts, but now it works consistently.

I've done some basic maintenance such as oil changes, spark plugs, air filters and brake maintenance.

04 / EMBEDDED SYSTEMS

NFC Smart Locker

Prototype · 103 project

This project allowed a user to either use a traditional lock or use a smartphone to lock a locker. The locker had an NFC coaster which sends the user to a web app (Flask) with a button to lock the locker. Once the user returned to the locker, they would scan the coaster and could unlock the locker. The web app uses a cookie on the users device to make sure other devices can't unlock the locker. I also fabricated a custom micro usb cable using a Dremel, solder and heat shrink because the provided cable was too large for the enclosure.

As a product, this system would be integrated into current locker systems and allow for gyms to create less waste cutting locks after closing, as there would be software for a manager to remotely open lockers. This project placed first at the ECEi Sharktank pitch competition.

Flask · NFC · SolidWorks

05 / MECHANICAL DESIGN

Water Filtration Unit

101 project · 2024

I designed, modeled and 3D printed a gearbox assembly using Solidworks, Bambu Studio and a Bambu Lab X1C. The project was a water filtration unit and the gearbox spun a mixing capsule, attached through the tank magnetically. The gearbox was designed to have a 16:1 gear ratio to spin the mixer in the water tank at a slow enough speed where the magnets would stay attached.

SolidWorks · Bambu Studio · Bambu Lab X1C
