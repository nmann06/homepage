Square Game

A two-player card game inspired by Iota. Players build lines where colour, shape and number are each all the same or all different, and completing a four-card line doubles the score. Rooms use a 4-digit code, with turn timers from one minute to seven days and email alerts for longer games. Node.js, Supabase, Resend and vanilla JavaScript.
